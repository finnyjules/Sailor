# Slice-Shift shader — design

**Date:** 2026-09-07
**Status:** approved, implementing

## What & why

A new catalog fragment shader `shader_effects/slice_shift.frag` that cuts its input into
thin bands and offsets each band along one axis — the "horizontal slice displacement" seen
on the Sónar 2020 poster (the giant **S** chewed into stepped, sawtooth-edged rows).

The point is a **versatile** primitive, not a one-off Sónar clone. Because it is a catalog
frag it is automatically usable as a **fill** on glyphs / shapes / brush strokes / frame
backgrounds / 3D surfaces (via `frontend/app/lib/shaderfill/field.ts`), and can later be
surfaced as a **post-stack** effect (one `POST_EFFECTS` entry) to shear *anything beneath it*.

## Why a new frag, not `block_glitch`

`block_glitch.frag` already does per-row horizontal offset sampling, but it structurally
cannot do the three things that make the Sónar look read as intentional letterform design:

1. It hard-codes `fragColor.a = 1.0`, so the **torn silhouette** (gaps reading *through* to
   what's behind) is impossible. Slice-shift is **alpha-aware**: it samples and displaces the
   input's own alpha, so shifted bands leave transparent gaps.
2. Its horizontal mode is a **sample-hold smear** (`p.x = mix(...)` streaks), not a clean
   per-band slice.
3. Band count is hard-coded (`floor(y*4.0)` / 3 bands). Slice-shift exposes **band size** as a
   dial (chunky ziggurat ↔ fine scanlines).

`block_glitch` stays untouched.

## Controls (manifest params)

Built-in uniforms provided by the catalog runtime: `u_image0`, `u_resolution`, `u_time`,
`u_seed`. All below are declared as manifest `params` (each: `uniform`, `label`, `type`,
`min`/`max`/`default`/`step`, and `enum` options for selects).

| uniform     | label      | type   | range / options                                  | default | note |
|-------------|------------|--------|--------------------------------------------------|---------|------|
| `u_axis`    | Axis       | enum   | 0 Horizontal · 1 Vertical · 2 Both               | 0       | H = bands stack on Y, shift in X (Sónar) |
| `u_band`    | Band size  | float  | 0.004 … 0.30 (fraction of perpendicular dim)     | 0.06    | large = chunky teeth; small = fine scanlines |
| `u_amount`  | Amount     | float  | 0 … 0.5 (fraction of dim)                         | 0.12    | how far each band shifts |
| `u_pattern` | Pattern    | enum   | 0 Random · 1 Wave · 2 Stair · 3 Ping-pong        | 0       | how per-band offset is chosen |
| `u_snap`    | Snap       | float  | 0 … 24 (0 = continuous, else N discrete stops)   | 0       | quantizes offset onto a grid → "typographic" feel |
| `u_wrap`    | Edge       | enum   | 0 Transparent · 1 Wrap                            | 0       | transparent gaps (Sónar) vs. smear edge solid |
| `u_ramp`    | Falloff    | enum   | 0 None · 1 Top→bottom · 2 Edges→center · 3 Radial | 0       | optional attenuation; None = Sónar-uniform |
| `u_speed`   | Speed      | float  | 0 … 4                                             | 0       | 0 = static poster treatment |
| `u_step`    | Step       | float  | 1 … 30 (jitter steps/sec)                         | 8       | snap-in-time vs. slide; only bites when speed>0 |

Category: `distortion`. `animated: true`. Single pass.

## Shader logic (contract)

- Perpendicular coord `c` and shift direction depend on `u_axis`:
  - Horizontal → band on `1.0 - v_texCoord.y`, shift in `x`.
  - Vertical → band on `v_texCoord.x`, shift in `y`.
  - Both → sum an X-shift from Y-bands and a Y-shift from X-bands.
- Band index `bi = floor(c / max(u_band, eps))`.
- Time quantization mirrors `block_glitch`: `tq = floor(u_time * u_speed * u_step) / u_step`.
- Per-band signed offset `o ∈ [-1,1]`:
  - Random: `hash2(vec2(bi, laneId) + tq, u_seed) * 2.0 - 1.0`.
  - Wave: `sin(bi * k + u_time * u_speed)`.
  - Stair: normalized monotone ramp of `bi` (→ shear / faux-italic).
  - Ping-pong: `mod(bi, 2.0) * 2.0 - 1.0`.
- Snap: if `u_snap >= 1`, `o = round(o * u_snap) / u_snap`.
- Falloff `f` from `u_ramp` (None → 1.0) multiplies the offset: `off = o * u_amount * f`.
- Displaced UV `suv = v_texCoord + offVec`.
- **Alpha-aware output:**
  - `u_wrap == 0` (Transparent): if `suv` is outside `[0,1]` → `fragColor0 = vec4(0.0)`;
    else `fragColor0 = texture(u_image0, suv);` — **full rgba, alpha preserved** (this is the
    core departure from `block_glitch`). Verify premultiplied-alpha handling in the renderer
    so transparent gaps don't render black.
  - `u_wrap == 1` (Wrap): `fragColor0 = texture(u_image0, clamp(suv, 0.0, 1.0));`.
